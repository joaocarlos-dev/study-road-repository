Ao construir uma aplicação, geralmente não é utilizado apenas o front-end ou back-end, precisamos de diversas coisas como bancos de dados, cache, mensagerias, etc, o Docker compose trás uma forma de resolver isso, através do Docker compose, ele é um arquivo orquestrador de [[Containers]], dentro dele você organiza e configura os containers que irão rodar para a sua aplicação, dessa forma você consegue rodar tudo com apenas 1 comando e subir uma aplicação inteira, seja um sistema de cache com redis, um banco de dados, uma mensageria, o back e o front, tudo isso pode ser rodado ao mesmo tempo e conversar entre si utilizando o compose.
